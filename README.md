# 🚀 Flutter Up - Comprehensive Flutter Packages Examples

A comprehensive Flutter project demonstrating various popular packages with detailed Turkish comments and modern UI implementations.

## ✨ Features

This project showcases the following Flutter packages with complete examples:

### 📱 **Shimmer Loading Effect**
- Realistic loading simulation with 3-second demo
- Multiple shimmer elements (profile pictures, text lines)
- Interactive demo with restart functionality
- Beautiful UI with gradients and shadows

### 🌐 **Connectivity Plus 7.0.0**
- Real-time connection monitoring
- Manual connection checking
- Connection history tracking
- Visual indicators for different connection types
- Supports WiFi, Mobile, Ethernet, VPN, Bluetooth

### 📤 **Share Plus 12.0.0**
- XFile API implementation
- Multiple sharing types: text, images, files, URLs
- Advanced sharing options with subject and position
- Share history tracking with timestamps
- Grid layout with interactive buttons

### 📷 **Image Picker**
- Camera and gallery integration
- File type restrictions (JPG, PNG)
- Comprehensive error handling

### 💾 **Shared Preferences**
- Data persistence examples
- Settings management
- User preferences storage

### 📅 **Date/Time Formatting**
- Internationalization examples
- Date formatting with Intl package
- Localized date displays

### 🎯 **Show Case Views**
- Interactive tutorials
- Feature highlighting
- User onboarding examples

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (>=3.4.3)
- Dart SDK
- Android Studio / VS Code
- iOS Simulator / Android Emulator

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ulasbaskirisci/FlutterUp.git
   cd FlutterUp
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```
